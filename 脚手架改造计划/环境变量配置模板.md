# 🔧 环境变量配置模板

## 📋 概述

本文档提供了基于 Dub 构建国际化 SaaS 产品所需的完整环境变量配置模板，包括开发环境和生产环境的配置。

## 📁 配置文件结构

```
your-project/
├── .env.example          # 环境变量模板 (提交到 Git)
├── .env.local           # 本地开发环境 (不提交到 Git)
├── .env.development     # 开发环境配置
├── .env.staging         # 预发布环境配置
└── .env.production      # 生产环境配置 (仅在 Vercel 中配置)
```

## 🔐 .env.example 模板

```bash
# =============================================================================
# 应用基础配置
# =============================================================================

# 应用名称
NEXT_PUBLIC_APP_NAME="YourApp"

# 应用域名 (不包含协议)
NEXT_PUBLIC_APP_DOMAIN="yourdomain.com"

# 短域名 (用于短链接，如果不需要可以与主域名相同)
NEXT_PUBLIC_APP_SHORT_DOMAIN="yourdomain.com"

# 部署环境 (development, preview, production)
NEXT_PUBLIC_VERCEL_ENV="development"

# Ngrok URL (本地开发时使用，可选)
NEXT_PUBLIC_NGROK_URL=""

# =============================================================================
# 数据库配置
# =============================================================================

# PlanetScale 数据库连接字符串
DATABASE_URL="mysql://username:password@host/database?sslaccept=strict"

# PlanetScale 数据库连接字符串 (边缘运行时)
PLANETSCALE_DATABASE_URL="mysql://username:password@host/database?sslaccept=strict"

# =============================================================================
# 认证配置
# =============================================================================

# NextAuth.js 密钥 (生成方式: openssl rand -base64 32)
NEXTAUTH_SECRET="your-nextauth-secret-key-here"

# NextAuth.js URL
NEXTAUTH_URL="https://yourdomain.com"

# Google OAuth
GOOGLE_CLIENT_ID="your-google-client-id.apps.googleusercontent.com"
GOOGLE_CLIENT_SECRET="your-google-client-secret"

# GitHub OAuth
GITHUB_CLIENT_ID="your-github-client-id"
GITHUB_CLIENT_SECRET="your-github-client-secret"

# Framer OAuth (可选)
FRAMER_CLIENT_ID=""
FRAMER_CLIENT_SECRET=""

# =============================================================================
# 支付配置 (Stripe)
# =============================================================================

# Stripe 密钥 (测试环境)
STRIPE_SECRET_KEY="sk_test_your-stripe-secret-key"
NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY="pk_test_your-stripe-publishable-key"

# Stripe Webhook 密钥
STRIPE_WEBHOOK_SECRET="whsec_your-webhook-secret"

# Stripe 应用密钥 (用于 Stripe Connect，可选)
STRIPE_APP_SECRET_KEY=""
STRIPE_APP_SECRET_KEY_TEST=""
STRIPE_APP_SECRET_KEY_SANDBOX=""

# =============================================================================
# 邮件服务配置 (Resend)
# =============================================================================

# Resend API 密钥
RESEND_API_KEY="re_your-resend-api-key"

# =============================================================================
# 缓存配置 (Upstash Redis)
# =============================================================================

# Upstash Redis REST API
UPSTASH_REDIS_REST_URL="https://your-redis-instance.upstash.io"
UPSTASH_REDIS_REST_TOKEN="your-upstash-token"

# =============================================================================
# 分析服务配置 (Tinybird)
# =============================================================================

# Tinybird API 密钥 (可选)
TINYBIRD_API_KEY="p.your-tinybird-api-key"

# =============================================================================
# 存储服务配置 (R2/S3)
# =============================================================================

# 存储基础 URL
STORAGE_BASE_URL="https://dubassets.com"

# AWS S3 / Cloudflare R2 配置 (可选)
STORAGE_ACCESS_KEY_ID=""
STORAGE_SECRET_ACCESS_KEY=""
STORAGE_ENDPOINT=""
STORAGE_BUCKET_NAME=""

# =============================================================================
# 监控和日志配置
# =============================================================================

# Axiom 日志服务 (可选)
AXIOM_TOKEN="xaat-your-axiom-token"
AXIOM_DATASET="your-app-logs"

# Sentry 错误监控 (可选)
SENTRY_DSN="https://your-sentry-dsn@sentry.io/project-id"

# =============================================================================
# 第三方集成配置 (可选)
# =============================================================================

# Slack 集成
SLACK_CLIENT_ID=""
SLACK_CLIENT_SECRET=""

# HubSpot 集成
HUBSPOT_CLIENT_ID=""
HUBSPOT_CLIENT_SECRET=""

# Segment 分析
SEGMENT_WRITE_KEY=""

# Shopify 集成
SHOPIFY_CLIENT_ID=""
SHOPIFY_CLIENT_SECRET=""

# =============================================================================
# 开发工具配置
# =============================================================================

# 跳过环境变量验证 (开发时使用)
SKIP_ENV_VALIDATION="false"

# 数据库日志级别 (development 时使用)
DATABASE_LOG_LEVEL="info"
```

```bash

openssl rand -base64 32

# 随机字符串
openssl rand -hex 32

```

- ✅ 使用最小权限原则
- ✅ 定期轮换 API 密钥
- ✅ 监控 API 使用情况
- ✅ 设置使用限制

### **3. 环境隔离**
```yaml
开发环境:
  - 使用测试 API 密钥
  - 连接开发数据库
  - 启用详细日志

  - 使用测试 API 密钥
  - 连接预发布数据库

  - 使用生产 API 密钥
  - 连接生产数据库
  - 启用监控告警
```

- ❌ 不要在代码中硬编码密钥

- ❌ 不要在日志中输出敏感信息

## 🛠️ 配置验证脚本

创建一个脚本来验证环境变量配置：

```typescript
// scripts/validate-env.ts
import { z } from 'zod';

const envSchema = z.object({
  // 应用配置
  NEXT_PUBLIC_APP_NAME: z.string().min(1),
  NEXT_PUBLIC_APP_DOMAIN: z.string().min(1),
  
  // 数据库
  DATABASE_URL: z.string().url(),
  
  // 认证
  NEXTAUTH_SECRET: z.string().min(32),
  NEXTAUTH_URL: z.string().url(),
  
  // 支付
  STRIPE_SECRET_KEY: z.string().startsWith('sk_'),
  NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY: z.string().startsWith('pk_'),
  
  // 邮件
  RESEND_API_KEY: z.string().startsWith('re_'),
  
  // 缓存
  UPSTASH_REDIS_REST_URL: z.string().url(),
  UPSTASH_REDIS_REST_TOKEN: z.string().min(1),
});

try {
  envSchema.parse(process.env);
  console.log('✅ 环境变量验证通过');
} catch (error) {
  console.error('❌ 环境变量验证失败:', error.errors);
  process.exit(1);
}
```

## 🔄 环境变量更新流程

### **1. 开发环境更新**
```bash
# 更新 .env.local
vim .env.local

# 重启开发服务器
pnpm dev
```

### **2. 生产环境更新**
```bash
# 通过 Vercel CLI 更新
vercel env add VARIABLE_NAME

# 或在 Vercel Dashboard 中更新
# 然后重新部署
vercel --prod
```

### **3. 批量更新**
```bash
# 使用 Vercel CLI 批量导入
vercel env pull .env.production
# 编辑后重新推送
vercel env push .env.production
```

## 📞 故障排除

### **常见问题**

#### **1. 数据库连接失败**
```bash
# 检查连接字符串格式
DATABASE_URL="mysql://username:password@host/database?sslaccept=strict"

# 确保包含 sslaccept=strict 参数
```

#### **2. 认证回调失败**
```bash
# 检查 OAuth 回调 URL 配置
# Google: https://yourdomain.com/api/auth/callback/google
# GitHub: https://yourdomain.com/api/auth/callback/github
```

#### **3. Stripe Webhook 失败**
```bash
# 检查 Webhook 端点配置
# URL: https://yourdomain.com/api/callback/stripe
# 事件: checkout.session.completed, invoice.payment_succeeded
```

#### **4. 邮件发送失败**

```bash
# 确保 SPF 和 DKIM 记录正确配置
```
