## 🏗️ 技术架构概览

### **基于 Dub 的成熟架构**
```
┌─────────────────────────────────────────────────────────────┐
│                    🌐 全球 CDN (Vercel)                      │
├─────────────────────────────────────────────────────────────┤
│  📱 前端应用 (Next.js 15 + React 19 + TypeScript)          │
├─────────────────────────────────────────────────────────────┤
│  🔗 API 层 (Next.js API Routes + 中间件)                   │
├─────────────────────────────────────────────────────────────┤
│  🗄️ 数据层 (Prisma ORM + PlanetScale MySQL)               │
├─────────────────────────────────────────────────────────────┤
│  🔐 认证 (NextAuth.js) | 💳 支付 (Stripe) | 📧 邮件 (Resend) │
├─────────────────────────────────────────────────────────────┤
│  ⚡ 缓存 (Upstash Redis) | 📊 分析 (Tinybird) | 📁 存储 (R2) │
└─────────────────────────────────────────────────────────────┘
```

### **核心技术栈**
- **前端**: Next.js 15, React 19, TypeScript, Tailwind CSS
- **后端**: Next.js API Routes, Prisma ORM, PlanetScale
- **认证**: NextAuth.js (支持 5+ 登录方式)
- **支付**: Stripe (支持 135+ 货币)
- **部署**: Vercel (全球边缘网络)
- **监控**: Vercel Analytics, Axiom

## 🔄 改造重点

### **业务逻辑层** (核心改造)
```typescript
// 当前：短链接管理系统
apps/web/app/api/links/     → 替换为核心业务 API
apps/web/ui/links/          → 重构为业务 UI 组件
apps/web/lib/analytics/     → 改造为业务数据分析

// 目标：你的核心业务功能
- 产品/服务管理
- 订单处理系统  
- 内容管理系统
- 用户生成内容
```

### **品牌定制** (轻度改造)
```typescript
// 品牌元素替换
packages/utils/src/constants/main.ts  → 应用名称和域名
apps/web/app/layout.tsx               → 页面元数据
apps/web/public/                      → 静态资源
```

### **数据模型调整** (按需改造)
```prisma
// 保留核心模型
✅ User, Project, Account, Session, Invoice

// 替换业务模型  
🔄 Link → YourBusinessEntity
🔄 Domain → YourDomainConcept
🔄 Tag → YourCategorySystem
```

## 🚀 快速开始

### **1. 环境准备**
```bash
# 克隆项目
git clone https://github.com/dubinc/dub.git your-project-name
cd your-project-name

# 安装依赖
pnpm install

# 配置环境变量
cp .env.example .env.local
# 编辑 .env.local 填入必要配置
```

### **2. 数据库设置**
```bash
# 推送数据库 schema
pnpm prisma:push

# 启动开发服务器
pnpm dev
```

### **3. 品牌定制**
```typescript
// 修改 packages/utils/src/constants/main.ts
export const APP_NAME = "YourApp";
export const SHORT_DOMAIN = "yourdomain.com";
```

### **4. 部署上线**
```bash
# 连接 Vercel
vercel

# 配置环境变量
vercel env add

# 部署到生产环境
vercel --prod
```
